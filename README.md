# Churn Modelling - Exploratory Data Analysis

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of the Churn Modelling dataset.

The objective is to understand customer characteristics, identify patterns in the data, and generate meaningful insights through data cleaning, statistical analysis, and visualization.

##  Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

##  Analysis Performed

- Dataset loading and initial inspection
- Understanding data structure and data types
- Checking for missing values
- Checking and handling duplicate records
- Descriptive statistical analysis
- Univariate analysis
- Bivariate analysis
- Outlier detection
- Data visualization
- Identifying important patterns and insights

##  Key Areas Explored

The analysis explores customer-related factors such as:

- Age
- Gender
- Geography
- Credit Score
- Balance
- Tenure
- Number of Products
- Active Membership
- Customer Churn

##  Project Files

- `churn_modelling_eda.ipynb` - Jupyter Notebook containing the complete EDA process.

##  Project Objective

The main objective of this project is to practice and demonstrate Exploratory Data Analysis techniques using Python and develop the ability to extract meaningful insights from customer data.
